# Player Lookup

The Player Lookup feature lets you search for any Minecraft player (Java or Bedrock) and view their profile, skin, and linked accounts.

---

## How to use it

1. Open MCCompanion and tap **Lookup** in the navigation bar
2. Enter a username, gamertag, or UUID/XUID
3. MCCompanion automatically detects whether it is a Java or Bedrock identifier
4. Tap **Search** to load the result

You can also access it from the website at [mccompanion.net/lookup](/lookup).

---

## What you can search

| Input type | Example | Edition |
|---|---|---|
| Java username | `Notch` | Java |
| Java UUID | `069a79f4-44e9-4726-a5be-fca90e38aaf5` | Java |
| Xbox gamertag | `ImJensCo` | Bedrock |
| XUID | `2535425170955552` | Bedrock |

---

## What the results show

### Java player
- Username and UUID
- Current skin (3D preview and download)
- Cape (if any)
- Whether the player has a linked MCCompanion account

### Bedrock player
- Gamertag and XUID
- Whether the player has a linked MCCompanion account

### Cross-linked players
If a player has linked both their Java and Bedrock accounts in MCCompanion, their full profile shows both identities side by side.

---

## Tips

- Searches are case-insensitive
- If a Java username returns no result, the Mojang API may be temporarily unavailable. Try again shortly.
- Bedrock lookups require the exact gamertag (spaces are supported)

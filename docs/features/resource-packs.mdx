# Resource Packs

MCCompanion supports server-side Resource Packs completely free. When a server uses a resource pack, it will automatically be applied when you join.

:::warning Early Access
Resource Pack support is currently in its **early testing phase**. You may encounter bugs or unexpected behavior. Please report any issues in our Discord.
:::

---

## Supported formats

Only `.zip` and `.mcpack` files are supported (Bedrock Edition format). Java Edition resource packs are **not** compatible.

---

## Why you need to clear your cache

Every time you join a server with a new or updated resource pack, Minecraft may hold on to a cached (saved) version of an old pack. This can cause the pack to not load, look broken, or show an "incompatible pack" error.

**Always clear your cache when:**
- You use a resource pack for the first time on a server
- A server's resource pack has been updated
- Your textures look wrong or aren't loading

---

## How to clear the server pack cache

### Android, iOS & Windows
1. Open Minecraft
2. Go to **Settings → Storage**
3. Tap **Clear Server Pack Cache**
4. Rejoin the server

### PlayStation
1. Open Minecraft
2. Go to **Settings → Storage → Cached Data**
3. Remove all listed server packs
4. Rejoin the server

### Xbox & Nintendo Switch
1. Fully close Minecraft
2. Reopen it — the cache clears automatically on restart
3. Rejoin the server

---

## Still not working?

Try these steps in order:

1. Restart your device
2. Clear the cache again and rejoin
3. Uninstall and reinstall Minecraft

# Server Tracker

The Server Tracker lets you monitor Minecraft servers in real time: see who's online, track uptime, and get notified when a server goes up or down.

---

## Adding a server

1. Open MCCompanion and go to the **Server Tracker** tab
2. Tap **Add server**
3. Enter the server **address** and **port** (default: `25565` for Java, `19132` for Bedrock)
4. Choose the platform: **Java** or **Bedrock**
5. Give the server a name and tap **Save**

MCCompanion immediately pings the server and displays its current status.

---

## What you can see

For each tracked server:

| Info | Description |
|---|---|
| **Status** | Online / Offline |
| **Player count** | Current / maximum players |
| **Version** | Server software version |
| **MOTD** | Server message of the day |
| **Ping** | Response time in ms |
| **Last seen online** | Timestamp of last successful ping |

---

## Notifications

Enable push notifications per server to get alerted when a server comes online or goes offline. Toggle notifications in the server's settings panel.

:::info
Push notifications require notification permissions to be enabled for the MCCompanion app on your device.
:::

---

## Tracker slot limits

The number of servers you can track depends on your subscription:

| Plan | Tracker slots |
|---|---|
| Free | 1 |
| Starter | 3 |
| Pro | 6 |
| Ultra | 10 |

---

## Removing a server

Swipe left on a tracked server (mobile) or tap the delete icon to remove it from your list.

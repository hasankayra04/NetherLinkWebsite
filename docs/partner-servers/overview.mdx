# Partner Server Program

The MCCompanion Partner Server Program lets server owners list their Minecraft server directly inside the MCCompanion app, reaching thousands of players who are actively looking for servers to join.

---

## Plans

| | Standard | Premium |
|---|---|---|
| **Price** | $15 / month | $50 / month |
| **Server slots** | Up to 30 | Up to 15 |
| Rotating spot in Featured Servers list | ✅ | ✅ |
| Rotating feature on the MCCompanion website | ✅ | ✅ |
| Rotating Discord Server of the Day | ✅ | ✅ |
| **Hero feature in the app** (largest placement on the connector page) | ❌ | ✅ |
| Stats dashboard | ✅ | ✅ |
| Invoice history | ✅ | ✅ |
| Cancel anytime | ✅ | ✅ |

The key difference: **Premium** gives your server the largest placement on the connector page, where users actively browse and pick a server to connect to. Standard rotates through the regular Featured Servers list.

Premium has a lower slot limit (15) to keep the hero placement exclusive and high-visibility.

To get started, contact **Jens.Co** on [Discord](https://discord.gg/xvaNzE35Rs).

---

## Requirements

To become a partner, you need:

1. A registered MCCompanion user account (via the app or [mccompanion.net/register](/register))
2. A Minecraft server that is publicly accessible (Java or Bedrock)
3. Approval from the MCCompanion team

Partners are **not created automatically**. You register as a regular user first, then contact us to request partner status.

---

## How to apply

1. Create a regular MCCompanion account if you don't have one
2. Contact **Jens.Co** via [Discord](https://discord.gg/xvaNzE35Rs) or the in-app bug report form
3. Provide your server address, a short description, and your MCCompanion username
4. Once approved, your account is promoted to partner and you gain access to the Partner dashboard at [mccompanion.net/dashboard](/dashboard)

---

## Managing your servers

After approval, log in at [mccompanion.net/dashboard](/dashboard) and open the **Partner Servers** tab.

### Add a server
- Click **Add server**
- Fill in the server name, address, port, description, and an optional icon URL
- Set the game mode and max player count
- Save. Your server is immediately listed in the app

### Edit a server
- Click the edit icon on any server
- Update any field and save

### Delete a server
- Click the delete icon. This removes the server from the app listing immediately

### Server slots
Each partner account has a set number of **server slots** (the maximum number of servers you can list at once). Your current usage is shown in the dashboard. Contact us if you need more slots.

---

## Server stats

The Partner dashboard shows connection statistics for each of your servers:

- Total connections (today, this week, this month)
- Daily connection chart (last 30 days)
- Active player estimates

Stats update in real time as players connect through MCCompanion.

---

## Billing & invoices

Subscriptions are billed monthly and can be cancelled at any time with a full refund guarantee. Invoices are available in the **Partner Servers → Invoices** section of the dashboard and are processed via Stripe.
